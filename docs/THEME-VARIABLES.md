## 0. THE MODEL — how a color reaches the screen

```
  [ YOUR 8 FIELDS ]        the only things you edit
   surface · ink · canvas · accent-1/2/3 · shadow · highlight
        │
        ├─ CSS derives (color-mix in oklab, :root block)
        │    surfaces 2/3 · card · border(s) · text tints · bg-app ·
        │    shadow-ink · raised-chrome/ring   ← never edit directly
        ├─ JS derives (theme.js DERIVED_MIXES, culori parity)
        │    the same set as -rgb triplets for rgba() composition
        └─ canvas reads (lattice/atoms/pixiworld via resolvedThemeVar)
             #c/#c2 repaint + Pixi atlas re-key on every apply
```

Rules: (1) never hardcode a color — the pin (gate A5) fails any new
literal outside the canonical zones; (2) consumers only ever read
variables; (3) new variables join a group below and get a slot meaning.

## 4. THE ALTER GUIDE — "I want to change X, where do I edit?"

| I want to… | edit | what re-derives | guard |
|---|---|---|---|

| one field for one theme | that field's line in the theme block | surfaces/borders/text/shadows/gradients that read it (auto via color-mix + DERIVED_MIXES) | same |
| the nesting/contrast relationships | the mix percentages in the :root derivation block AND `DERIVED_MIXES` in theme.js (they must match — culori parity, the v099-calibrate law) | every theme at once | theme twins battery |
| a tone (ok/warn/err/notice) | the tone pair in each `[data-theme]` block (value + `-rgb` alias) | pills, dots, banners, cost colors | pin |
| text sizes | `--chat-fs`/`--ui-fs` statics + the Settings sliders (appearance.js writes them) | the whole message scope via --chat-scale | — |

## 5. THE RULES (short form)

1. **No literal colors outside the canonical zones** — the pin (`scripts/v1390-theme-source-pin.py`, gate A5) fails the battery on any NEW one; fixed ones must leave the baseline (`--update`).
2. **Fields are the only sources** — a derived value is never edited directly; tune the mix in both the CSS block and `DERIVED_MIXES`.
3. **Canvas obeys the same flip contract** — a theme apply repaints #c/#c2 and re-keys the Pixi atlas (themeStamp).
4. **This doc is generated** — after any theme-system edit, re-run `python3 scripts/v1391-theme-catalog.py` and commit the refresh.
