# Doomalay Docker Sandbox

A full-toolchain Linux sandbox for the [Doomalay](https://github.com/ScoobyBaby1999/doomalay)
app: real **bash**, **python**, **git**, **Node 20**, **gcc/g++/make/cmake**,
**Go**, **Rust**, **Java 17** — driven by a Doomalay HF chat.

Built automatically by the Doomalay engine (brick by brick via the HF API).
Chat protocol: `POST /chat` (engine → brain, SSE). Access is token-gated.
